このサイトはフレームワークを使わず、素のHTML / CSS / JavaScriptだけで作られています。将来Django版・React版を作るときの「答え合わせ」ができるように、仕組みをここに整理しておきます。

## 全体の構成

```
v.1-Portfolio/
├── index.html        トップページ(プロフィール・経歴・プロジェクト・記事の一覧)
├── projects.html      プロジェクト一覧ページ
├── blog.html          ブログ記事一覧ページ
├── post.html          ブログ記事詳細ページ
├── css/style.css       全ページ共通のスタイル
├── js/                 ページごとの表示ロジック
├── data/                プロフィール・経歴・プロジェクト・記事一覧などのデータ(JSON)
└── posts/               各記事の本文(Markdownファイル)
```

## データと表示を分けている

プロフィールや経歴、プロジェクト、記事の一覧はすべて `data/` フォルダの中のJSONファイルに書かれています。HTML側にはデータを書かず、JavaScriptがJSONを読み込んで画面に描画する、という役割分担にしています。

これは将来Djangoに置き換えるときに、

- `data/*.json` の各項目 → Djangoの「モデル」(データベースのテーブル)
- JSONを読み込んで表示するJavaScript → Djangoの「ビュー」+「テンプレート」

という対応関係になるように、あえてこの構成にしています。

## ブログ記事の仕組み

`data/posts.json` に記事の一覧(タイトル・日付・タグ・本文ファイルへのパス)がまとまっています。本文自体は `posts/` フォルダの中に、Markdown形式の `.md` ファイルとして置かれています。

記事一覧ページ(`blog.html`)は `posts.json` を読み込んで一覧を表示し、記事詳細ページ(`post.html`)はURLの `?slug=` に対応する記事を探して、その `.md` ファイルの中身をMarkdownからHTMLに変換して表示しています。

新しい記事を追加するときは、

1. `posts/` に新しい `.md` ファイルを追加する
2. `data/posts.json` に、その記事の情報を1件追加する

この2ステップだけで記事が増える仕組みになっています。
