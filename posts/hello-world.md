はじめまして、cobotechです。

このサイトは、自分の学習の記録と作ったものをまとめておくためのポートフォリオサイトです。

## このサイトを作った理由

- 学んだことをアウトプットする場所が欲しかった
- 自分が何をしてきたかを、あとから見返せる形で残しておきたかった
- 「作りながら学ぶ」を実践するための最初の題材にしたかった

## 今後の方針

今回のサイトはAIと一緒に、HTML / CSS / JavaScriptだけで作りました。ビルドツールやフレームワークを使っていないので、コードを読めばすべての仕組みが理解できるようになっています。

今後は次のステップで、このサイト自体を自分の力で作り直していく予定です。

1. Python / Djangoを学び、バックエンドで同じ機能を再現する
2. Reactを学び、フロントエンドをコンポーネント単位で作り直す

学習の過程は、このブログに随時書いていきます。
